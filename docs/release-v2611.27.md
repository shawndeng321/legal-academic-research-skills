# v2611.27 发布说明

[返回首页](../README.md) · [文档索引](README.md) · [上游 v1.6 整合说明](upstream-integration-v2611.27.md)

三技能与技能包统一为 `2611.27.0`，公开标签为 `v2611.27`。本版将 `law-paper-writing` 从上游 **v1.5** 增量同步至 **v1.6**（提交 `9e6507a`），强化引注实质忠实度逆向核验与改稿压缩防失真；`legal-research-wiki` 与 `legal-wiki-audit-repair` 的业务规则、参考文档、模板和脚本保持不变，仅随包同步版本号与文件锁。

## 本版变化

- **正文—原文实质忠实度逆向核查**：定稿前脱离起草记忆重新打开原始文件逐句比对，长文或大幅改稿建议在新会话或独立只读复核中执行；`citation-audit.md` 拆分为形式链路核查与实质忠实度核查两部分，`workflow.md` 全文修改增设第4轮“引注回原核验轮”。
- **法条、条约、案例与新闻通稿边界**：按所涉材料触发法条与条约四查（请求方向与编章、分款主体与“但书/除外”前提、禁常识外延适用对象、禁未见条约全文推定常见条款、排查外文法典 `Draft`/非官方译本偏移）；区分典型案例“法院实际裁判结果”与发布机关“典型意义/裁判要点”；会晤报道如实复述表态，禁拔高为“达成共识”；联网检索摘要与合成链接归入 `LEAD_ONLY`，有权威纸媒版面时优先引纸媒。
- **改稿压缩防失真与结构性去 AI 套话**：明确合句不并款、缩句不混样本、对仗不添事实、拆句重对注位，禁止“句末/段末一注兜底半句无据推演”；识别自造连字符/加号公式词、跨界公文黑话与同构段落模具；补齐复刻样稿页眉核对、对外修改说明与正文条号数据同步及内部工具词脱敏检查。
- **合理写法保护与新增场景**：保护明示作为立法/条约磋商参照的规范论证、据官方双语本核准条号并按手册第84条标注的外国法引注、有正式出处的带符号专有提法及局部修改范围边界；新增 `law-paper-writing/evals/citation-fidelity-cases.md`（C1—C12），写作评估场景由 71 项增至 83 项。

## 非写作模块与来源保护

`legal-research-wiki` 与 `legal-wiki-audit-repair` 保持 v2611.13 已发布的全部建库、摄入、深检、保守增量与插件目录保护行为不变，未改动任何业务文件或脚本。写作模块原有的 DOCX 真实脚注脚本（`md2docx_footnotes.py`）、实证与群案材料细则、知识库 note-level 溯源、共享更新器、多宿主适配（Codex、Hermes、Devin、Google Antigravity、DeepSeek Harness）及引注 7 分册结构完整保留。逐文件适配记录见[整合说明](upstream-integration-v2611.27.md)。

## 安装与更新

按[首页安装说明](../README.md#安装)复制三个**完整技能目录**，或通过已有普通源码安装的自动更新流程升级（更新前先备份本地修改并确认差异）。宿主管理的插件目录仍受拒写保护，请勿将源码更新器指向插件树。升级完成后请新建会话以加载新版 `SKILL.md`。

## 验证与边界

本版完成写作上游整合回归测试、技能体积与兼容性契约检查、全仓 Markdown 相对链接检查、`prepare_bundle_release.py --check` 指纹一致性校验，以及独立只读子会话对 C1—C12 的盲测核验（12/12 符合预期行为边界）。其余历史评估场景与非写作模块沿用既有基线边界（见 [2026-11 非写作更新说明](nonwriting-updates-2026-11.md#验证与已知限制)），不将未重跑的历史场景计作本轮模型实测；机器检查不能替代真实论文的法条、条约、案例与文献原件核查。
