# v2611.13 发布说明

[返回首页](../README.md) · [文档索引](README.md) · [GitHub Release](https://github.com/shawndeng321/legal-academic-research-skills/releases/tag/v2611.13)

三技能与技能包统一为 `2611.13.0`，公开标签为 `v2611.13`。本版停止维护 Claude Code 专用适配，并正式发布此前已验收的17项非写作优化。

## 本版变化

- 删除仓库中的 Claude Code 插件与 marketplace 清单、现行安装/更新命令和专用宿主映射；新发布清单不再声明 `claude_code` 兼容。
- 版本工具直接维护三个技能及 README，不再依赖已删除的插件元数据。发布工具在生成新清单时清除旧的兼容标记，同时保留其他兼容字段和历史条目。
- 继续提供 Codex、Hermes、Devin、Google Antigravity、DeepSeek Harness 的完整技能目录与宿主说明。
- 保留通用插件目录保护：路径含完整 `plugins` 组件时拒绝直接覆盖；Antigravity 渠道保持 `antigravity-plugin`，其他插件树为 `managed-plugin`，普通源码安装为 `bundle`。
- 正式收录[17项非写作优化](nonwriting-updates-2026-11.md)，包括 PDF 复用、检查结果分级、完整 JSON、真实页面关系、可选增量与异常回退。默认全量与人工核验要求保持。

## 写作与来源保护

写作规则继续采用上游 **v1.5**。五问触发、必读路由、交接、阶段顺序、至少三轮改稿、来源登记、论点核验、DOCX 真实脚注与引注核查均保留。本次写作目录的差异限于宿主说明、共享更新器、版本元数据、安装和发布记录。

MIT 署名、来源说明、三技能分工、单一主写、原件/提取物/核验记录、页码/案号、法律时效、备份、DRY_RUN、逐页回读与只读审计要求保持。旧版 CHANGELOG、来源整合文档和开发计划保留原文；其中 Claude Code 描述仅属于当时的版本。

## 安装与更新

从 Release 下载 `legal-academic-research-skills-v2611.13.zip`，或单个技能的同版本 ZIP，解压后按[安装说明](../README.md#安装)复制**完整技能目录**。需要固定源码时，克隆标签 `v2611.13`；需要当前源码时使用 `main`。

现有普通源码安装可以使用原有更新流程；先备份本地修改，再按提示确认。旧插件安装不再提供本版的专用更新入口；改用受支持宿主时，在该宿主的正常技能目录安装，避免把源码更新器指向任何插件树。宿主配置、模型与个人研究材料不属于本包发布内容。

## 验证与边界

本版对版本工具、清单迁移、插件目录拒写、Antigravity 渠道和普通源码更新进行定向回归，并对最终候选执行完整测试与独立结构/行为复核。实际结果和未通过项以本版 Release 列出的记录为准；历史测试成绩不冒充本版结果。

Windows 基线已有一项指纹断言失败和四项符号链接权限错误，本次不修改写作测试或系统权限来消除这些记录。Python 3.9 是兼容目标，不等于已在该版本实际运行；现有 `NORM-03` 详情只列前六条。增量模式在原合成小库基准中没有普遍提速证据，仍默认全量。机器检查不能替代来源核验、页码回读、法律时效判断或学术判断。
