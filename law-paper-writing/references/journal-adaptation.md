# 目标期刊适配

## 期刊要求优先

CSSCI是来源期刊评价体系，不是统一投稿格式。不得为所有法学来源期刊设定同一字数、摘要、关键词、节数、引注、匿名、审稿期限或一稿多投规则。

适配前复制 `assets/templates/journal-profile.md`。证据优先级为：

1. 目标期刊官网、正式投稿系统或编辑部发布的现行且针对当前稿件的正式要求；
2. 编辑部针对作者或本次投稿发出的可核验书面通知；
3. 期刊近期正式刊发稿件中可稳定观察的版式，仅作为生产格式的辅助推断；
4. 通用学术写作惯例，仅作为未指定期刊时的工作稿方案。

正式要求发生冲突时，先比较适用对象、栏目、稿件类型、版本或生效日期和核验日期：对当前稿件更具体且仍然有效的要求优先。刊发版式不得推翻明确的投稿说明；冲突仍无法解决时标为 `CONFLICT` 并向编辑部核实，不得自行选择。第三方经验帖只能作为线索。

每项期刊要求分别记录原始来源、版本或生效日期、核验日期和状态，不得只给整张期刊卡设置一个笼统来源。

## 期刊风格观察卡（可选）

正式要求之外，期刊常有稳定的行文偏好：实证切入还是规范切入、案例如何分组引用、标题风格、是否偏好某些标点。用户希望贴近某刊风格时：

1. 先检查用户资料或知识库中是否已有该刊的风格观察笔记（例如放在 `methodology/` 目录）。有则读取，行文方式参考该笔记；
2. 没有时，建议用户提供该刊近期正式刊发的 2—3 篇范文，据此整理一张风格观察卡：记录样本篇目、观察到的写法、观察日期；
3. 风格观察卡属于上文证据优先级第 3 级，只能辅助表达和版式，不得推翻正式投稿要求，也不得冒充编辑部规定；
4. 换刊时新建观察卡，不沿用其他期刊的风格。

某些期刊或编辑偏好减少破折号、以分句、冒号或括号承担解释功能。这属于期刊或个人偏好，只在观察卡或用户明确要求时执行；执行时保留文献原题名中的破折号和数字范围连接号。

## 无目标期刊

生成通用工作稿，并明确：

- 篇幅只是写作预算；
- Markdown 脚注只是中间格式；
- 生成 DOCX 工作稿时，先沿用用户已确认的页面参数或获准样稿；没有这些约束才选可逆的临时方案。例如可选上下 2.54 厘米、左右 3.18 厘米，但须标“本稿暂定”，不宣称所有软件、地区都以此为默认；目标期刊正式要求优先；
- 摘要、关键词、匿名和参考文献形式尚待适配；
- 不提供虚构的审稿周期、撤稿期限或独家等待期。

未指定目标期刊时，引注默认按《法学引注手册》（第二版）体例生成工作稿（见 [引注格式规范](citation-format.md)）；同时，不要把《法学引注手册》或 GB/T 7714 自动描述为所有法学期刊的统一强制标准。[GB/T 7714-2025](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C6CE52E55AC09B9C79A20AEA77CEDD14) 的实施日期为 2026 年 7 月 1 日（核验于 2026-07-29），但是否适用于具体稿件仍取决于目标期刊要求。

用户在未确定期刊时要求“给唯一参数立即排版”，按以下固定形状输出：

1. 先说明不存在 CSSCI 统一投稿规格；
2. 将数字单列为“本稿临时排版参数（非 CSSCI 或期刊标准）”；
3. 对正文、摘要、关键词和标题层级逐项标注“暂定，可逆”；
4. 将引注先设为便于转换的 Markdown 脚注工作格式，格式默认按《法学引注手册》体例（见 [引注格式规范](citation-format.md)）；
5. 将一稿多投、撤稿、独家等待、匿名和附件等程序性事项列为“待确定目标期刊后核验”，不得自行指定。

不得使用“CSSCI 通用标准”“CSSCI 通用工作稿规格”或其他容易让临时参数看似行业规范的名称。

## 适配项目

逐项核对：

- 选题范围与栏目；
- 正文、摘要和其他组成部分的篇幅；
- 中文、英文题名与摘要；
- 关键词数量与格式；
- 标题层级；
- 脚注、尾注、顺序编码或著者—年份制；
- 参考文献表要求；
- 匿名和作者信息；
- 基金、利益冲突、数据与伦理声明；
- 图表、附件和文件格式；
- 投稿伦理、一稿多投和撤稿程序。

## 摘要与关键词

摘要应准确呈现问题、材料或方法、主要论证与结论，不得写入正文未证明的创新或数据。是否使用结构式摘要、摘要长度、英文摘要词数和关键词数量服从期刊要求；未指定期刊且用户没有其他要求时，可把 [引注格式规范](citation-format-paper-items.md) 第17、18条的建议作为临时工作参数：摘要 200～300 字、不分段、不加引注，关键词 3～5 个；须明确可逆，不是统一 CSSCI 规格。

写或改摘要时，按下列功能位、写法与自查清单执行。

### 四个功能位

| 功能位 | 要回答的问题 | 合格标准 |
|---|---|---|
| 问题及其重要性 | 本文要解决什么矛盾？谁、在什么情形下受到影响？ | 第一句就进入本文的问题，不以意义、背景或常识起笔 |
| 既有研究的不足 | 既有研究在哪一点上没有解决这个问题？ | 一句点明不足落在哪里，不铺陈研究现状 |
| 主要观点与创新 | 本文给出的判断、标准、分类或方案是什么？ | 是可以检验、可以反驳的具体判断，不以“分析”“探讨”“提出建议”等研究动作代替；创新须是正文已经证明的 |
| 论证结果 | 这一判断解决了什么、适用到哪里？ | 陈述结果与边界，不评价本文的价值 |

材料或方法对理解结论确有必要时（如实证研究的样本与方法），在问题位或观点位中交代一句。功能位是内容要求，不是句数要求：一位可以用一句写完，也可以与相邻一位合写。

### 写法

1. 从正文找出承载四个功能位的核心观点句，作为摘要的材料；摘要中的观点、数据和术语都应能在正文找到。
2. 把这些句子编辑重组为一段通顺的短文；可以改动原句，但不大段照搬原文。
3. 用平实的陈述句写；“本文”不属于第一人称，可以使用，但能直接陈述观点时，不必先写“本文认为”。

### 自查清单

逐条检查，任何一条不通过就修改：

- [ ] 四个功能位都有实质内容，没有只有一两句、读不出创新之处的情况？
- [ ] 删去第一句，读者会损失信息吗？不会，说明它只是意义铺垫；
- [ ] “既有研究的不足”写明了不足落在哪里？
- [ ] 主要观点是一个具体判断，而不是研究动作？
- [ ] 末句陈述的是论证结果，而不是对本文价值的评价？
- [ ] 删去套语后，每句仍有内容；没有第一人称、比喻、口语、夸张形容词、谦辞、写作过程，也没有可作两种理解的句子？
- [ ] 观点、数据与术语与正文一致，没有正文未证明的内容？

### 常见套语类型

| 类型 | 识别特征 | 为什么不合格 | 改法 |
|---|---|---|---|
| 意义口号起笔 | 以“重要抓手”“关键环节”一类定位语开头 | 人所共知的定位，不是本文的问题 | 第一句直接写矛盾及受影响者 |
| 成效—问题套语 | “取得成效的同时也存在问题” | 没有说出问题是什么 | 写出具体问题 |
| 空泛的不足 | 只写“针对已有研究的不足” | 没说不足在哪里 | 写明既有研究没有解释什么 |
| 研究动作代替观点 | “多维度剖析”“提出对策建议” | 只说做了什么，读不出结论 | 写出判断、标准或方案本身 |
| 自评收尾 | “以期……”“具有重要意义” | 主观评价，缺乏客观性 | 写论证得出的结果与适用边界 |
| 铺陈研究现状或背景 | 大段介绍研究现状、常识或引言内容 | 挤占观点篇幅 | 压缩为一句“不足”，背景删去 |
| 复述与过程 | 复述标题或目录；“历时数月收集” | 不提供新信息 | 删去 |
| 修辞与谦辞 | 比喻；“如火如荼”；“粗浅探讨” | 意思不确切或没有信息 | 改为平实陈述或删去 |

起草摘要时只按本节执行，不读示例。诊断或修改已有摘要时，可以参考 [合成摘要示例](../assets/examples/abstract-examples.md) 中一个合格摘要的逐句标注；示例只用来解释本节规则，不得沿用其题目、术语、句式和句数。

### 关键词

标示论文的核心主题，不使用过分特别（其他研究者难以联想到）或过分普通（缺乏识别度）的词；数量与格式服从期刊要求，未指定期刊时见第18条。

### 英文题名与摘要

英文题名与摘要在中文内容稳定后处理；核对法律术语、机构名称和法律文本的权威译法，不逐字机器翻译。

## 完成声明

只有在每项适用的适配要求都有可追溯正式来源并处于 `VERIFIED` 状态，且每项 `NOT_APPLICABLE` 都有明确理由时，才可声明“已按目标期刊要求完成适配”。`NOT_APPLICABLE` 必须说明其适用范围和据以判断的来源；不得遗留 `PARTIAL`、`LEAD_ONLY` 或 `CONFLICT` 状态。否则列出已适配、待确认、冲突和无法核验事项。
