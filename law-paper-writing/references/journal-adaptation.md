# 目标期刊适配

## 期刊要求优先

CSSCI是来源期刊评价体系，不是统一投稿格式。不得为所有法学来源期刊设定同一字数、摘要、关键词、节数、引注、匿名、审稿期限或一稿多投规则。

适配前复制 `assets/templates/journal-profile.md`。证据优先级为：

1. 目标期刊官网、正式投稿系统或编辑部发布的现行且针对当前稿件的正式要求；
2. 编辑部针对作者或本次投稿发出的可核验书面通知；
3. 期刊近期正式刊发稿件中可稳定观察的版式，仅作为生产格式的辅助推断；
4. 通用学术写作惯例，仅作为未指定期刊时的工作稿方案。

正式要求发生冲突时，先比较适用对象、栏目、稿件类型、版本或生效日期和核验日期：对当前稿件更具体且仍然有效的要求优先。刊发版式不得推翻明确的投稿说明；冲突仍无法解决时标为 `CONFLICT` 并向编辑部核实，不得自行选择。第三方经验帖只能作为线索。

每项期刊要求分别记录原始来源、版本或生效日期、核验日期和状态，不得只给整张期刊卡设置一个笼统来源。

## 期刊风格观察卡（可选）

正式要求之外，期刊常有稳定的行文偏好：实证切入还是规范切入、案例如何分组引用、标题风格、是否偏好某些标点。用户希望贴近某刊风格时：

1. 先检查用户资料或知识库中是否已有该刊的风格观察笔记（例如放在 `methodology/` 目录）。有则读取，行文方式参考该笔记；
2. 没有时，建议用户提供该刊近期正式刊发的 2—3 篇范文，据此整理一张风格观察卡：记录样本篇目、观察到的写法、观察日期；
3. 风格观察卡属于上文证据优先级第 3 级，只能辅助表达和版式，不得推翻正式投稿要求，也不得冒充编辑部规定；
4. 换刊时新建观察卡，不沿用其他期刊的风格。

某些期刊或编辑偏好减少破折号、以分句、冒号或括号承担解释功能。这属于期刊或个人偏好，只在观察卡或用户明确要求时执行；执行时保留文献原题名中的破折号和数字范围连接号。

## 无目标期刊

生成通用工作稿，并明确：

- 篇幅只是写作预算；
- Markdown 脚注只是中间格式；
- 生成 DOCX 工作稿时，先沿用用户已确认的页面参数或获准样稿；没有这些约束才选可逆的临时方案。例如可选上下 2.54 厘米、左右 3.18 厘米，但须标“本稿暂定”，不宣称所有软件、地区都以此为默认；目标期刊正式要求优先；
- 摘要、关键词、匿名和参考文献形式尚待适配；
- 不提供虚构的审稿周期、撤稿期限或独家等待期。

未指定目标期刊时，引注默认按《法学引注手册》（第二版）体例生成工作稿（见 [引注格式规范](citation-format.md)）；同时，不要把《法学引注手册》或 GB/T 7714 自动描述为所有法学期刊的统一强制标准。[GB/T 7714-2025](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C6CE52E55AC09B9C79A20AEA77CEDD14) 的实施日期为 2026 年 7 月 1 日（核验于 2026-07-29），但是否适用于具体稿件仍取决于目标期刊要求。

用户在未确定期刊时要求“给唯一参数立即排版”，按以下固定形状输出：

1. 先说明不存在 CSSCI 统一投稿规格；
2. 将数字单列为“本稿临时排版参数（非 CSSCI 或期刊标准）”；
3. 对正文、摘要、关键词和标题层级逐项标注“暂定，可逆”；
4. 将引注先设为便于转换的 Markdown 脚注工作格式，格式默认按《法学引注手册》体例（见 [引注格式规范](citation-format.md)）；
5. 将一稿多投、撤稿、独家等待、匿名和附件等程序性事项列为“待确定目标期刊后核验”，不得自行指定。

不得使用“CSSCI 通用标准”“CSSCI 通用工作稿规格”或其他容易让临时参数看似行业规范的名称。

## 适配项目

逐项核对：

- 选题范围与栏目；
- 正文、摘要和其他组成部分的篇幅；
- 中文、英文题名与摘要；
- 关键词数量与格式；
- 标题层级；
- 脚注、尾注、顺序编码或著者—年份制；
- 参考文献表要求；
- 匿名和作者信息；
- 基金、利益冲突、数据与伦理声明；
- 图表、附件和文件格式；
- 投稿伦理、一稿多投和撤稿程序。

## 摘要与关键词

摘要应准确呈现研究问题、主要论证与结论；材料或方法对理解结论确有必要时一并交代，不得写入正文未证明的创新或数据。摘要应独立成篇，脱离正文仍可读懂。是否使用结构式摘要、摘要长度、英文摘要词数和关键词数量服从目标期刊正式要求。

未指定期刊且用户没有其他要求时，中文摘要以 **350～400 字为起草目标**，不分段，不加引注。这一字数是工作预算，不是所有法学期刊的统一标准，也不是内容合格与否的唯一依据；不设最低字数，不为凑字数添加无信息的铺垫，偏离起草目标时应说明必要信息或内容缺口。关键词仍按 [引注格式规范·论文事项](citation-format-paper-items.md) 第18条，暂以 3～5 个为工作参数。手册第17条的来源建议另予保留，不与本技能的起草预算混同。

写或改摘要时，按下列内容要求、写法与自查清单执行。

### 内容要求

| 内容 | 要求与判断标准 |
|---|---|
| 研究问题 | 能读出所要解决的具体矛盾或解释困难；涉及受影响对象时说明对象，不强制统一问题句式 |
| 核心观点 | 写出具体、可检验或可反驳的判断、标准、分类或方案，不以“分析”“探讨”“提出建议”等研究动作代替；创新须是正文已经证明的 |
| 既有研究的不足 | 视需要交代。观点足够具体时，可不单独交代；单列时写明不足落在哪里，不写空泛的不足句 |
| 论证结论与适用边界 | 呈现正文已经得出的结果和必要限定，可与核心观点合写；不强制另列结果句或以边界句收尾，不评价文章自身价值 |

内容要求不是固定句数、句序或逐项填空要求。开头可以交代为后文论证提供前提的背景，仅说明意义的定位语不宜写入。“随着……”“近年来……”等开头按这一原则判断，不按关键词自动判错。

实证研究中影响结论可信性和适用范围的样本、材料或方法应当交代，可直接融入结论表述；规范解释研究不必强写方法名称。结论句已体现方法和层次的，不再另述研究方法、论文目录或研究步骤。

### 写法

1. 从正文找出承载研究问题、具体观点和结论的句子，按需要补充研究不足及必要材料，作为摘要的材料；摘要中的观点、数据和术语都应能在正文找到。
2. 把这些句子编辑重组为一段通顺的短文；可以改动原句，但不大段照搬原文，不要求各项内容分别占一句。
3. 用平实的陈述句直接写已经得出的观点和结论。不写“我认为”“笔者认为”“本文认为”“研究提出”“本文将论证”等自指或研究动作表达，也不以“据此提出”“在此基础上提出”转场；“本文拟”“本文试图”“本文旨在”“本研究提出”等同类说法改为直接陈述具体判断、标准或方案。本条适用于摘要，正文的自我指涉仍按 [正文表达](legal-prose.md) 处理。
4. 不删除有依据的限定：法律判断中的“应当”不属于计划语气；有证据理由的“可能”“在……范围内”应保留，不为显得肯定而提高结论强度。
5. 摘要不加注释，不作“以下简称……”交代，使用读者能直接识别的名称；摘要不加注不免除正文对应内容的引注责任。
6. 学术表达以术语准确、意思明确为标准，不靠生僻词、拉长句子或堆砌概念，不设“必须第三人称”的机械要求。

### 自查清单

逐条检查；不适用的条件项不要求补写，偏离起草字数目标时说明原因，不单凭数字判定内容不合格：

- [ ] 能读出研究问题、具体核心观点和论证结论，而不只剩“存在问题—深入分析—提出建议”？
- [ ] 开头如写背景，是否为后文论证提供必要前提，而非只说明意义或热度？不把“删除首句不损失前提”当成删除实质问题句、观点句的理由。
- [ ] 如写研究不足，是否有具体落点？观点足够具体而未单列不足的，不据此判错。
- [ ] “存在问题”“关键症结”“完善机制”等概括语是否有具体内容？正文没有答案的，回正文补论证，不在摘要中补造。
- [ ] 观点和结论是否直接陈述，没有研究动作、目录复述或价值自评？结论可与观点合写，不强制末句另写结果或边界。
- [ ] 是否没有用无助于理解判断的常识、共识占篇幅？必要前提不因属于背景或常识而一律删除。
- [ ] 是否没有自指引导语、研究动作转场、第一人称、比喻、口语、夸张形容词、谦辞、写作过程、注释、简称交代或含义不清的表述？
- [ ] 观点、数据、术语和结论强度是否与正文一致？必要样本、材料、方法和适用限定是否保留？
- [ ] 未指定期刊且用户没有其他要求时是否以 350～400 字为起草目标？偏离时有无必要信息或内容缺口的说明，而非机械判错或凑字？有期刊要求时是否改按已核验要求？

### 常见套语类型

| 类型 | 识别特征 | 为什么不合格 | 改法 |
|---|---|---|---|
| 意义口号起笔 | “重要抓手”“关键环节”“突破口”等仅说明意义的定位语；“随着……”“近年来……”引出而不构成论证前提的背景 | 没有提供理解问题或结论所需的信息 | 删去纯意义铺垫，保留必要前提；不按开头关键词自动判错 |
| 成效—问题套语 | “取得成效的同时也存在问题” | 没有说出问题是什么 | 写出具体问题 |
| 空泛的不足 | 只写“针对已有研究的不足”“现有研究尚不充分” | 没说不足在哪里 | 如需交代就写明落点；观点足够具体时可不单列，不为形式完整补写 |
| 研究动作代替观点 | “多维度剖析”“提出对策建议”“本文试图”“研究提出”“本文将论证”“据此提出”“在此基础上提出”等 | 只说做了什么，读不出结论；或以无必要的动作语引出观点 | 直接写出判断、标准或方案本身 |
| 自评收尾 | “以期……”“具有重要意义”“具有开创性意义”“理论上有重大突破”“选题新颖”等 | 主观评价，不能代替研究结论 | 写实际结果与必要限定，可与观点合写，不强制另占末句 |
| 铺陈研究现状或背景 | 大段介绍研究现状、无助于理解结论的常识或重复引言内容 | 挤占具体观点的篇幅 | 压缩无关研究现状，不足按需要交代；保留论证必要前提，删去只说明意义的背景 |
| 复述与过程 | 复述标题或目录；“第一部分……第二部分……”；“历时数月收集” | 不提供判断所需的新信息 | 删去目录复述或过程介绍，保留确有必要的材料与方法信息 |
| 修辞与谦辞 | 比喻；“如火如荼”；“粗浅探讨”“谈谈粗浅看法”“一点尝试” | 意思不确切或没有信息 | 改为平实陈述或删去 |

起草摘要时只按本节执行，不读示例。诊断或修改已有摘要时，可以参考 [合成摘要示例](../assets/examples/abstract-examples.md) 的逐句标注；示例只解释内容怎样落到句子上，不是字数完整示范，不得沿用其题目、术语、句式和句数。

### 关键词

标示论文的核心主题，不使用过分特别（其他研究者难以联想到）或过分普通（缺乏识别度）的词；数量与格式服从期刊要求，未指定期刊时见第18条。

### 英文题名与摘要

英文题名与摘要在中文内容稳定后处理；核对法律术语、机构名称和法律文本的权威译法，不逐字机器翻译。

## 完成声明

只有在每项适用的适配要求都有可追溯正式来源并处于 `VERIFIED` 状态，且每项 `NOT_APPLICABLE` 都有明确理由时，才可声明“已按目标期刊要求完成适配”。`NOT_APPLICABLE` 必须说明其适用范围和据以判断的来源；不得遗留 `PARTIAL`、`LEAD_ONLY` 或 `CONFLICT` 状态。否则列出已适配、待确认、冲突和无法核验事项。
