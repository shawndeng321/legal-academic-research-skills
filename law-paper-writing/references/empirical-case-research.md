# 实证、群案与统计材料的使用细则

用于以案例群、裁判文书样本、调研数据或统计结果支撑法学论证的论文。论证方法总纲见 [论证诊断](argumentation-diagnostics.md) 的“按命题检查理由”；来源与数据的核验要求见 [证据核验](evidence-and-legal-validity.md)。本文件只补充“怎样把材料用对”，不替代两者。

以下示例均为合成说明，不代表任何真实研究的结论或数据。

## 一、先定材料在论文中的角色

大样本案例库、裁判文书检索结果或调研数据，通常是**素材库**，不是论文必须全部使用的内容。法学论文的骨架一般是一个法律问题加规范论证；大样本最常承担三种辅助角色：

1. **问题切入**：用一两句样本内描述说明争议确实存在；
2. **选材来源**：从中挑选权威性强、事实清楚、能暴露关键差别的案例深入分析；
3. **统计佐证**：进入表格或脚注，支持“这种分歧并非个例”一类的有限判断。

写大纲前先与用户确认案例配置：正文深入分析多少个、脚注引用多少个、是否需要全样本统计。篇幅、问题类型和目标期刊风格都会影响这个配置，不设统一数量。选择原则：

- **类型化覆盖优先于数量**：每种争点类型选能代表不同处理方式的案例，权威来源（指导性案例、公报案例、典型案例）优先；
- **深度与广度分工**：正文详析负责展示判断过程，统计样本负责说明分布，两者不冲突；
- **避免稀释论证**：逐案罗列而不归纳，是论证缺失，不是材料丰富。

如果用户的研究本身就是实证法学或计量研究，按其研究设计执行，但仍须遵守下文的口径与外推限制。

## 二、从材料到判断：排除竞争解释

从案例或数据得出概括性判断时，不能从“现象”直接跳到“结论”。在材料与结论之间至少要回答：

1. **有哪些可能的竞争解释？** 常见类型包括：个案裁量差异（结果无规律）、价值偏好（例如倾向保护某一方）、制度过渡期（新规范施行初期的暂时混乱）、样本选择造成的假象。只检查与当前判断实质相关的解释，不凑数量。
2. **材料能否区分这些解释？** 例如：若某种结果来自价值偏好，就难以解释样本中同一判断逻辑也导向相反结果的案件；若来自过渡期，则应随时间减少。用材料中可复核的特征回应，而不是用措辞否定对方。
3. **无法排除时怎么办？** 保留该解释，相应缩窄结论，写明“现有材料不足以区分”。

可参考的段落推进（不是固定句式）：先陈述观察到的现象 → 提出一至两个最有力的竞争解释 → 说明材料中哪些特征不支持或支持它们 → 在剩余解释的范围内提出判断 → 交代边界与反例。

**实证只能证明“实践如何”。** “应当如何”的规范结论另需规范论证（制度目的、规范文本、体系关系、价值取舍），见 [论证诊断](argumentation-diagnostics.md)。

## 三、统计口径必须先定稿再计算

统计前把以下口径写下来并经用户确认，否则结果不可复现，也容易出现两套数字：

- **结果类别的定义**：例如“改判”是否包括撤销后责令重作、程序性撤销、发回重审；
- **归类规则**：模糊或混合结果归入哪一类，边界案例如何处理；
- **分母**：是否剔除程序性案件、无法判定案件、年份不详案件；
- **时间切片**：按哪个日期（一审、终审、公布日期）归年，时间不明时如何处理；
- **无法判定项**：文本未明确说明结果时标“无法判定”，不根据上下文推测。

逐案归类必须基于裁判文书或原始材料的文字。统计完成后，附一份样本性质说明：来源、选取方式、是否随机、时间与地域分布。

### 两套口径并存时

- 不静默覆盖：先找出差异来源（哪一项定义或归类不同），列出差异表；
- 以用户确认的定稿口径为论文数据源；另一套口径可作为稳健性说明或删去；
- 发现定稿版缺少对论证有用的数据（如分层结果、方向结构）时，作为“可选补充”提给用户，不自行替换。

## 四、样本限制与表述红线

- **非随机样本**的所有比例都要带“样本内”限定，不得外推为总体比例；
- **分布不均**（某些年份、地区或层级样本很少）时，只描述分布，不声称趋势；
- **来源结构突变**（某一时段的样本主要来自某一类汇编）时，先归因于样本结构，再考虑实质变化；
- **样本结构本身可以是论证材料**，但须说明推理，例如“进入权威汇编的案例多为被纠正的案件”只能支持关于汇编选择机制的判断，不能直接支持关于全部实践的判断；
- 主动在方法部分交代样本构成，回应“代表性”质疑。

## 五、统计结果落地后同步论点表

数字算出来之后，不能只在文末加一句“统计已完成”，也不能把所有“待核”一律改为已核验。逐条回到 [论点—证据—引注表](../assets/templates/claim-evidence-matrix.md)：

1. 找出仍标“待核”“缺证据”“统计待执行”的条目，与最新结果逐项比对；
2. 区分“数字已经算出”与“这个数字足以支持该命题”，前者不自动推出后者；
3. 为每条统计性主张记录口径版本、样本范围、分母、无法判定项、反方材料和代表性限制；
4. 只有确实被支持的主张才改状态；仍需定性分析、竞争解释或反方处理的，维持待核或改为较弱表述；
5. 历史前提句（如“样本尚未整理”）改为复核记录，保留审计轨迹；
6. 交付前核对研究设计、论点表、统计结果与交接说明中的数字和状态是否一致。

**验收标准**：每个统计性主张都能回答“数字从哪里来、支持到哪一步、不能推出什么”。

## 六、改稿时的继承与修改标注

- 改稿继承说明、在旧稿基础上增量发展的顺序，见 [论证诊断](argumentation-diagnostics.md) 的“改稿继承关系说明”。
- 用户需要审阅 AI 改动时，可同时交付“干净版”和“修改标注版”（新增或改写的段落、脚注以红色标出），并附修改清单：改了什么、为什么、哪些细微调整未标注。生成方法见 [DOCX 生产](docx-production.md)。
- 插入的新内容独立成段，不追加在原段落末尾，否则标注和排版都容易出错。

## 七、交付前检查

- [ ] 大样本是否只承担切入、选材和佐证角色，而非替代规范论证？
- [ ] 每个概括性判断是否处理了实质相关的竞争解释？
- [ ] 统计口径是否在计算前定稿，并在正文或注释中交代？
- [ ] 比例是否限定为样本内，分布是否没有被写成趋势？
- [ ] 论点表、研究设计与正文中的数字和核验状态是否一致？
- [ ] 目标期刊对摘要字数、关键词数量、标点和脚注格式的要求是否已按 [期刊适配](journal-adaptation.md) 核验？
