# 引注审核

## 一、形式与链路核查

- [ ] 每项来源性主张后均有对应标识
- [ ] 正文标识与脚注双向对应
- [ ] 每条脚注能追到来源编号和原始资料
- [ ] 来源登记中的完整著录、原始位置、精确定位、核验日期和允许用途完整
- [ ] 最终稿所用来源均为 `VERIFIED`，无 `PARTIAL`、`LEAD_ONLY` 或 `UNUSABLE`（无仅凭检索摘要或合成链接直接转正的条目）
- [ ] 直接引语均有精确位置
- [ ] 转述、二手转引和译文均已说明
- [ ] 法律规范版本及效力已经核验
- [ ] 案件名称、案号、法院和日期已经核验
- [ ] 数据口径、范围、时间和发布者完整
- [ ] 无孤立参考文献或脚注
- [ ] 适用的必填字段完整；不适用的条件字段明确标注 `N/A` 并说明依据；可选备注可留空
- [ ] 无虚构字段、`[待核]`、待补充或待核验等未完成占位
- [ ] 适用引注体例已确定：目标期刊正式要求、用户确认体例或手册默认工作体例；差异已说明
- [ ] 再次引用可准确回到首次引注；未定稿不提前略写，改号后交叉核对
- [ ] 标点、文号、书名号和外文斜体一致，格式调整未改变原始标识或掩盖来源缺口

## 二、正文—原文实质忠实度核查（定稿必查；局部修改仅查受影响引注）

- [ ] 已脱离对话记忆重新打开原始文件逐条比对，未仅凭起草印象勾选
- [ ] 正文转述未添加原文没有的适用对象、结论强度或“达成共识”等拔高概括
- [ ] 法条或规范性文件的“但书”“除外”等限定前提完整保留，多款不同主体的规定未混写为一句
- [ ] （如涉及程序法、涉外法或国际条约）条文的请求方向、编章归属准确，强制要件与可拒绝事由未混同，未见全文处未凭常识推定条款
- [ ] （如涉及域外法律或译本）已排查立法草案译本或非官方译本条号偏移，无跨源版本冲突
- [ ] （如涉及指导性案例或典型案例）已区分法院实际裁判结果与发布机关“典型意义/裁判要点”评述
- [ ] （如涉及统计或转引实证数据）多组独立样本的来源与分母分开交代，未因压缩句子混拼
- [ ] 引注符号紧随其实际支撑的分句，无“句末/段末一注兜底半句无据推演”情形
