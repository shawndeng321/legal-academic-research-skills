# 投稿前检查

- [ ] 目标期刊卡有正式来源和核验日期
- [ ] 题目、摘要、引言、正文和结论回应同一主问题
- [ ] 摘要未加入正文没有证明的结论
- [ ] 结语回应引言并提炼已证结论，未强加展望或超出论证范围
- [ ] 研究不足与本文推进相呼应；实际涉及法定要件或比较法时，分别核对要件对应或借鉴限度
- [ ] 涉及证明责任或实体程序衔接时，已交代主体、程序、事实不明后果及衔接依据
- [ ] 标题层级、篇幅、引注和文件格式符合期刊要求
- [ ] 作者信息、基金和致谢按匿名要求处理
- [ ] 利益冲突、数据、伦理及AI使用声明按要求处理
- [ ] 法律和事实资料截止日期已声明
- [ ] 引注审核（含形式链路与正文—原文实质忠实度）全部通过
- [ ] 正文及随附对外修改说明均不含本地路径、Obsidian双链、内部辅助工具话术（如Skill、“去AI味”等）或私人信息
- [ ] 如导出DOCX或同时交付多份修改文档，已确认使用真实脚注、无旧模板残留，且修改说明中的法条号、数据与脚注总数同正文一致
- [ ] 一稿多投、撤稿和附件要求已核对
